# ICONCRETE — مولد مصنف Excel المحمول

**ICONCRETE — Concrete Management Solutions**

حزمة Python مستقلة تولّد ملف `.xlsx` حقيقياً لإدارة محطات الخرسانة الجاهزة. تعمل محلياً وداخل
Google Colab بدون خادم، وبدون مفاتيح API، وبدون خدمات مدفوعة، وبدون الحاجة إلى Microsoft Excel
Desktop، وبدون تعديل يدوي في كود Python لتغيير الإعدادات العادية.

- اللغة العربية هي الافتراضية واتجاه الأوراق RTL، مع تسميات إنجليزية لكل ورقة.
- الهوية مقفلة: **ICONCRETE** وتحتها **Concrete Management Solutions**.
- اسم الملف يحتوي طابعاً زمنياً `IConcrete_YYYYMMDD_HHMMSS.xlsx` ولا يتم الكتابة فوق أي ملف سابق.

## المتطلبات

- Python 3.9 أو أحدث (تم الاختبار على 3.12)
- `openpyxl` إصدار 3.1.x، و`pytest` إصدار 8.x للاختبارات

```bash
python3 -m venv .venv
.venv/bin/pip install -r excel_generator/requirements.txt
```

## التوليد

```bash
python3 excel_generator/generate_workbook.py
```

المخرجات في `excel_generator/output/IConcrete_<timestamp>.xlsx` (مستثناة من Git).

خيارات إضافية:

```bash
python3 excel_generator/generate_workbook.py \
  --output-dir ./output \
  --from 2026-05-01 --to 2026-10-28 \
  --no-protection            # بدون حماية الأوراق
  --no-charts                # بدون رسوم الداشبورد
  --empty                    # بدون صفوف تجريبية
```

## الإعداد

عدّل القيم الافتراضية في `excel_generator/config.py` أو مرّر `GeneratorConfig` من Python أو من
الدفتر: هوية الشركة والمحطة، العملة، اللغة، المنطقة الزمنية، فترة التقرير، مجلد المخرجات، نسبة
الضريبة، وحماية الأوراق وبيانات العرض. قيم الهوية تأتي من Addendum A1 ولا تُغيّر في المنتج.

## Google Colab

1. ارفع مجلد `excel_generator` إلى Colab أو استنسخ المستودع.
2. افتح `IConcrete_Generator.ipynb`.
3. شغّل الخلايا من ١ إلى ٩ بالترتيب. الخلية ٤ (الإعدادات) هي الوحيدة التي تحتاج مراجعة عادةً.

الدفتر يثبّت المتطلبات، ويسمح اختيارياً بربط Drive أو رفع ملفات، ثم يولّد المصنف، ويجري الفحوصات
الآلية، ويطبع سجلاً، وينزّل الملف. لا يحتاج AI Studio ولا بيانات GitHub ولا مفاتيح API ولا Excel مثبتاً.

| `Materials` | افتتاحي/وارد/صادر/رصيد مع قيمة المخزون |

| `Orders` | التسعير والضريبة والإجمالي وفحص سقف الائتمان |

الميزات: جداول Excel حقيقية، صيغ بدلاً من أرقام مكتوبة، تثبيت رؤوس، قوائم منسدلة، تنسيق شرطي،
حماية خلايا الصيغ، خلايا إدخال بخلفية صفراء قابلة للتحرير، RTL كامل، أسماء نطاقات، ورسوم بيانية.
حماية الأوراق تمنع التعديل العارض فقط وليست حداً أمنياً.

## قواعد التحقق المطبقة

| القاعدة | المكان |
|---|---|
| عائد الخلطة 0.98–1.02 م³ | صيغة في `Mix_Designs` + `Validation_Report` |
| W/C حسب التعرض (XC1 0.60، XC4 0.45، XS2 0.45، XS3 0.40) | صيغة + تقرير |
| سقف ائتمان العميل | `Orders.CreditCheck` + تقرير |
| قيم سالبة في المخزون/الحجم/الائتمان | تقرير التحقق |
| معرّفات مكررة ومراجع مفقودة وحالات غير صحيحة | تقرير التحقق |
| ترخيص شاحنة ينتهي خلال 30 يوماً | `Fleet` + تقرير |

تحتوي `calc.py` القواعد نفسها كدوال نقية (العائد، تصحيح الرطوبة، حفظ المياه، W/C، الائتمان،
المتوسط المرجح، إجمالي الطلب، الجودة، عمر الخرسانة، الإهلاك، جدول القرض) والاختبارات تغطيها.

## الاختبارات

```bash
python3 -m pytest excel_generator/tests -q
```

تتحقق من: إنشاء الملف، فتحه بـ openpyxl، وجود كل الأوراق المتوقعة، الجداول والعناوين والصيغ
وأسماء النطاقات والقوائم المنسدلة، وجود ثلاث رسوم بيانية، RTL لكل ورقة، نص الهوية على ورقة
الدخول، حماية خلايا الصيغ مع بقاء خلايا الإدخال قابلة للتحرير، اكتشاف سيناريوهات الخطأ المقصودة،
نظافة البيانات التجريبية، عدم الكتابة فوق ملف سابق، وصحة قواعد الحساب مقابل القيم المرجعية.

## حدود صريحة (بدون ادعاءات كاذبة)

لا يوفر الملف مزامنة سحابية حية، ولا فرض RLS على PostgreSQL، ولا تحققاً بخطوتين فعلياً، ولا اتصال
GPS/SCADA/IoT حقيقياً، ولا إرسال واتساب/SMS فعلياً، ولا Power Query/Data Model/Power Pivot/DAX
أصلية، ولا تفويض API على الخادم. كل ذلك ممثل فقط بواجهات إعداد وقوالب استيراد/تصدير ومسار ترحيل
موثق. كل صف تجريبي موسوم `DEMO` ويجب حذفه قبل الاستخدام الحقيقي.

## العلاقة بتطبيق الويب

قاعدة البيانات هي مصدر الحقيقة عند ربط التطبيق. Excel يُستخدم فقط كمصنف بداية/أوفلاين، وقالب
استيراد، وصيغة تصدير/تقارير، وقالب إدخال مُراقب. مركز تكامل Excel يتحقق من كل صف مرفوع، ويولّد
تقرير أخطاء، ولا يكتب فوق سجل موجود بصمت، ويسجل عملية تدقيق لكل رفع وتحقق واستيراد وتصدير وصف مرفوض.

راجع `docs/EXCEL_GENERATOR_CHANGELOG.md` لسجل التغييرات.
